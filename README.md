# Calculadora de Obras AP y AS

Herramienta docente de Hidráulica Urbana (UC): módulos independientes para dimensionar y verificar obras de agua potable y aguas servidas según NCh691:2015, NCh1105:2019, NCh777 y NCh2811-2006, y esquemas dibujables del sistema AP y AS.

Sitio estático de un solo archivo (`index.html`), sin compilación. Publicado con Cloudflare Pages.
